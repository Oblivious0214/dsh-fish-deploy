# DSH 养鱼部署包

## 给人类看

通过几个插件组合，让 DSH 获得类似 QQ 的聊天界面，并支持角色扮演。兼容表情包和 AI 语音 TTS 插件，不用准备 QQ 小号，也省去养鱼小号被封的顾虑。

**把本项目链接发给 DSH，让它帮你部署即可。**

项目链接：https://github.com/Oblivious0214/dsh-fish-deploy

## 给 DSH 看

当用户将本项目链接交给你进行部署时，请完成基础安装，再引导用户设置聊天外观和人格，最后按需添加表情包、语音功能。

### 一、安装基础插件

当前验证环境为 DSH `0.2.1-rc.3-22ddee3`。先检查当前版本、profile 和已安装插件，核对兼容性。

| 插件 | 版本 | 安装包 |
| --- | --- | --- |
| [人设切换](https://github.com/Oblivious0214/dsh-toy-persona/tree/feat/dsh-toy-persona) | `0.3.1-toy.13` | [TGZ 安装链接](https://github.com/Oblivious0214/dsh-toy-persona/releases/download/v0.3.1-toy.13/dsh-persona-switcher-0.3.1-toy.13.tgz) |
| [QQ 聊天界面](https://github.com/Oblivious0214/dsh-toy-qq/tree/feat/dsh-toy-qq) | `0.2.0-toy.4` | [TGZ 安装链接](https://github.com/Oblivious0214/dsh-toy-qq/releases/download/v0.2.0-toy.4/dsh-qq-skin-0.2.0-toy.4.tgz) |

使用内置 `plugin_manager` 的 `install_bundle` 操作，将 TGZ 直链作为 `target`，安装到当前 profile 并启用。

已安装目标版本时跳过，已有更新的 Toy 版本时保留。升级前备份配置，保留角色库、会话绑定、头像背景及已有设置。如发现旧版 `dsh-toy-persona`、`dsh-toy-qq` 或独立分段插件，处理替换，避免重复启用。

安装后核对实际版本和启用状态，按返回结果提示重启。附件尚未公开、下载失败或存在兼容问题时，说明原因并停止。

### 二、引导用户配置聊天界面和人格

基础插件加载成功后，向用户介绍以下入口，并询问其偏好：

- **更换头像**：点击聊天头像可以换图；也可以在人设设置中给角色设置默认头像，手动设置的会话头像优先。
- **是否切分段落**：询问用户喜欢“一条完整回复”还是“像 QQ 一样分成多个气泡”。在「设置 → QQ聊天界面 → 对话分段 → 启用分段显示」调整，需要时再设置分段间隔。
- **设置人格**：提醒用户先到「设置 → 人设切换」添加角色，填写角色名称、性格、说话方式和背景；也可以从输入框下方「人设 → 添加人设」进入。
- **开始扮演**：提醒用户在对话前，从输入框下方的「人设」菜单选中想聊天的角色。设置了默认人设时，也应确认当前对话已采用该角色；未选中人设时沿用 DSH 原有设定。

「沉浸式 QQ」默认开启。用户找不到回复下方的复制、评价等按钮时，告知可在 QQ 设置中关闭。

### 三、需要表情包时

基础配置完成后，询问用户是否需要表情包。需要时安装并启用：

- 项目：[dsh-meme](https://github.com/yyh-001/dsh-meme)
- GitHub 安装目标：`github:yyh-001/dsh-meme`

引导用户打开「设置 → 表情包」，安装或导入喜欢的图库，确认对应图库已启用，并按偏好调整主动发表情和发送方式。

之后可到人设设置中打开角色的「表情偏好」，选择优先图库、标签和发表情频率。提醒用户：角色偏好使用的图库仍需先在 dsh-meme 中安装并启用；频率通过提示词引导模型。

### 四、需要 AI 语音时

用户需要语音回复时，安装并启用：

- 项目：[dsh-fish-tts](https://github.com/MaRi23333/dsh-fish-tts)
- GitHub 安装目标：`github:MaRi23333/dsh-fish-tts`

然后按顺序引导用户完成配置：

1. **注册账号**：打开 [Fish Audio 注册页](https://fish.audio/auth/signup/) 注册并登录。
2. **获取 API Key**：进入 [Fish 开发者控制台](https://fish.audio/app/developers/)，在 API Keys 中创建密钥，让用户自行填入 DSH「设置 → 语音朗读／Fish TTS」的连接设置并保存。
3. **寻找音色**：打开 [Fish 音色库](https://fish.audio/discovery/)，搜索、试听喜欢的声音，进入音色详情页，复制音色 ID（`reference_id`）。
4. **配置音色**：将 ID 填入 Fish TTS 设置的「音色 ID」，点击「应用音色」；按插件和账号可用项选择模型，再点击试听确认。
5. **绑定角色**：如希望不同角色使用不同声音，在「设置 → 人设切换」中点击对应角色的「绑定音色」，填写该角色的音色 ID，试听后保存。
6. **开启语音回复**：打开输入框下方的「语音／语音回复」开关，再到「设置 → QQ聊天界面」选择语音与文字的显示方式，以及自动生成或点击生成。

当前角色音色通过 Fish 的全局默认音色同步，多窗口同时使用时不保证音色隔离。遇到认证、额度或模型权限问题时，引导用户检查 Fish 控制台及插件错误提示。

### 五、完成部署

最后简要说明：

- 两个基础插件是否安装、启用，是否需要重启。
- 用户选择的头像、分段方式和当前人格。
- 表情包、语音是否已配置，还有哪些步骤需要用户完成。

已有配置尽量保留；表情包和语音按用户需要添加。
