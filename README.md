# DSH 养鱼部署包

把这个项目链接交给 DSH，让它帮你安装和配置 QQ 聊天式角色扮演。

**给 DSH 的部署说明：** [原始文档](https://raw.githubusercontent.com/Oblivious0214/dsh-fish-deploy/main/README.md) · [安装清单](https://raw.githubusercontent.com/Oblivious0214/dsh-fish-deploy/main/deploy.json)

## 给人类看

当前公开提供 QQ Bot 聊天插件。设备联动仍在私有开发，暂不提供公开安装。

| 项目 | 用途 | 本次内测版本 |
| --- | --- | --- |
| [dsh-qqbot](https://github.com/Oblivious0214/dsh-qqbot) | QQ 界面、角色库、提示词预设、分段、语音、中文聊天摘要与角色记忆 | 0.1.31 |

需要 DSH **0.2.1-rc.3 或通过插件兼容检查的更高版本**。安装后，在新会话的预设中选择 **QQ Bot**。插件不会改变标准预设或全局默认，也不会更改沙箱和权限。

首次使用会提供“大肥鱼”和默认提示词，内容可自行修改；已有资料不覆盖。语音已包含在 QQ Bot 内，可连接 Fish Audio、OpenAI 兼容服务或 GPT-SoVITS，不需要另装 Fish TTS。表情包按需使用 [dsh-meme](https://github.com/yyh-001/dsh-meme)。

旧的 `dsh-toy-segments`、`dsh-toy-qq`、`dsh-toy-persona` 已停止维护，功能由新 QQ Bot 承接。旧 Release 保留追溯，不再作为新安装目标。新插件不自动导入旧角色、会话或配置。

当前为内测：手机局域网／远程入口尚未迁入新版；设备联动尚未完成，仓库及安装包暂不公开。

## 给 DSH 看

当用户要求部署本项目时，按本页和 `deploy.json` 执行。当前部署说明版本为 **0.2.1**。优先使用已构建的 TGZ，不克隆源码、不自行编写安装程序、不发布 npm。

### 1. 检查实际运行版本与安装入口

1. 从当前实例、关于页或该实例的安装信息确认 DSH 版本。低于 `0.2.1-rc.3`、版本不明、用户暂不更新或更新失败时，结束整套部署，不先安装其他可选插件。更新完成并重新启动、核对版本后才继续；不要扫描整个磁盘。
2. 更高版本仍须通过宿主的插件兼容检查；不绕过检查或审批，不改变沙箱和权限。
3. 查看实际工具表是否有 `plugin_manager`。有则调用 `{"action":"list_bundles","limit":100}`，有下一页时继续。没有就使用当前安装提供的 CLI 或“插件”页，不改工具设置来获取它。
4. CLI 使用 `dsh plugin --profile <实际 profile> add "<TGZ 链接>"`。Desktop 的 CLI 可能位于实际安装目录的 `resources/runtime/cli/bin/dsh.cmd`。确认当前 profile，不猜测安装路径或 profile，不重新安装 DSH，不手改依赖清单代替安装器。

### 2. 备份与已有插件处理

安装前备份实际 profile 的 `package.json`、`pnpm-lock.yaml`、`cordis.patch.yml` 和受影响插件目录，记录备份位置。使用与该 profile 匹配的 pnpm，避免重建整个依赖目录；安装后核对目标包与清单变更。

识别旧 `dsh-toy-segments`／`dsh-chat-segments`、`dsh-toy-qq`／`dsh-qq-skin`、`dsh-toy-persona`／`dsh-persona-switcher`。发现时说明新插件不导入旧资料，根据用户授权停用旧插件并保留其数据；尚未授权时先请用户决定，不直接删除或覆盖。不要并行启用旧 QQ／人设／分段来拼接新版功能。

发现其他全局美化插件时，只指出具体可能冲突的项，按用户选择处理，不批量停用其他插件。已安装 dsh-fish-tts 时提醒避免双重朗读，不修改它的全局音色或配置；新版语音在 QQ Bot 中单独设置。

旧 `dsh-toy-buttplug@0.2.0-preview.*` 与新插件同名但架构不同，不能当成新版直接跳过。先说明会替换旧包、不导入旧设置，备份并获得替换授权后才安装；不直接删除旧资料。新版 `0.1.x` 已安装目标或更新版本时保留，不为匹配本文降级。

### 3. 安装 QQ Bot

| 插件 | 版本 | TGZ | 下载页 |
| --- | --- | --- | --- |
| QQ Bot | 0.1.31 | [下载安装包](https://github.com/Oblivious0214/dsh-qqbot/releases/download/v0.1.31/dsh-qqbot-0.1.31.tgz) | [Release](https://github.com/Oblivious0214/dsh-qqbot/releases/tag/v0.1.31) |

实际存在 `plugin_manager` 时，安装请求为：

```json
{"action":"install_bundle","target":"https://github.com/Oblivious0214/dsh-qqbot/releases/download/v0.1.31/dsh-qqbot-0.1.31.tgz","enabled":true}
```

按返回状态和 `nextStep` 处理启用或错误。需要重启时告知用户；没有明确授权不自行重启 DSH。失败保留已完成步骤，不继续安装尚未授权的可选项目。

### 4. 引导开始聊天

1. 新会话中主动选择 **QQ Bot**，不要把它设为全局默认。
2. 到“设置 → QQ Bot”或角色菜单“管理角色…”修改角色、默认提示词、界面和语音。仅首次无资料时加入内置角色，已有资料不覆盖；不直接改写用户设定。
3. 分段、中文摘要、角色记忆由插件管理；不另外安装分段或人设插件。配置包通过编辑器“导入配置”预览并确认，不能直接复制旧插件数据文件。
4. 如需语音，在 QQ Bot 的语音页添加服务和音色，再给角色选择音色。密钥由用户在设置中填写，不要求发到聊天中。支持按段由 AI 选择语音或全部转语音。
5. 如需表情包，按用户选择安装 `dsh-meme@0.1.65`，检查宿主兼容性，在它的设置中启用图库，再到角色页设置表情偏好。不更改其他插件文件。

### 5. 设备联动（暂未公开）

联动插件仍在私有开发，暂不提供公开安装或下载。本流程不安装联动插件，不连接或启动实体设备；待项目方确认完成后再开放。

### 6. 下载失败与继续安装

先核对 DSH、pnpm／Node 的实际网络及代理路径。Git 的代理不等于 TGZ 下载代理；不因一次超时判断包损坏，不展示带凭据的代理地址，不擅自改系统或全局代理，不关闭证书校验。

直接安装下载失败后，可从相同 Release 链接备用下载一次，超时设 30 秒，保存到实际 profile 的持久缓存，例如 `plugin-cache/`。核对 `deploy.json` 中该包的名称、版本与 SHA-256，确认后通过 `file:` 绝对路径安装，Windows 路径使用正斜杠，保留缓存文件及来源记录。摘要不符立即停止，不能绕过宿主兼容检查，也不为了安装降级其他依赖。

备用下载也失败时，**暂停当前部署并结束本轮，等待用户提供缺少的 TGZ 附件**：仅给出尚缺包的上表直链和 Release 备选页，说明不用解压，拖入当前 DSH 对话即可。不后台重试、轮询或继续其他安装配置。

收到附件后读取实际文件，不能只相信文件名；校验清单中的名称、版本及 SHA-256，保存到持久缓存，重新确认当前 DSH 版本后从未完成步骤继续。附件不可读或不匹配时继续等待正确附件，不安装。无需为同一已授权的安装任务重复确认。

### 7. 完成与关闭

汇报安装版本、启用状态、备份位置、用户还需填写的设置和是否需要重启，不把安装成功说成设备或语音已连接。保留用户原有资料和其他插件。

停用 QQ Bot 前，若用户自己将其设成全局默认，请先在 DSH“Agent 预设”中改回标准模式。插件不会替用户更改全局默认；停用期间旧 QQ Bot 会话无法打开，重新启用后可以恢复。
